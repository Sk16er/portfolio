# Shushank's Portfolio

Source code for my personal portfolio website, built to showcase projects, technical skills, and ongoing work in software engineering, machine learning, and web development.

**Live Site:** https://shushank.site

## Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS
* shadcn/ui
* Aceternity UI

### Animation & Interaction

* GSAP
* Framer Motion
* Spline Runtime

### Backend & Utilities

* Resend
* Socket.IO
* Zod

## Local Development

### Prerequisites

* Node.js
* npm or Yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/Sk16er/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Features

* Responsive design
* Interactive UI and animations
* Project showcase section
* Skills and experience overview
* Contact integration
* SEO optimization
